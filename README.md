# Hero OOP Project

Учебный проект по объектно-ориентированному программированию на Java.

## Описание
Проект представляет собой симуляцию битвы героев. В коде реализованы:
* Классы `Hero` и `Warrior`.
* Инкапсуляция (приватные поля, геттеры и сеттеры).
* Наследование и вызов `super()`.
* Полиморфизм (переопределение методов).

## Как запустить
1. Склонируйте репозиторий.
2. Откройте проект в IntelliJ IDEA.
3. Запустите класс `Main`.
